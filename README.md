# S3 Browser

A clean, minimal Next.js web app for browsing S3-compatible object storage (MinIO, Ceph, AWS S3, etc.).

## Quick Start

```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) and enter your S3 credentials.

## Features

- 🔐 Login with S3 endpoint + credentials
- 📦 Browse buckets and files
- 📁 Virtual folder navigation
- ⬆️ File upload
- 🔒 Bucket ACL management

## Stack

- Next.js 14+ (App Router)
- TypeScript
- Tailwind CSS
- AWS SDK v3 (server-side only)
